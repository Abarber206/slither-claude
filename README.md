# slither.claude

A Claude-themed slither.io-style browser game: start tiny, end enormous.

**Play:** https://abarber206.github.io/slither-claude/

- **Parties:** tap *Create party*, send friends the 5-letter code (or the invite link ending in `#party-CODE`). No sign-in needed.
- **Public arena:** stay Online without a party to play with whoever else is on.
- **Worlds:** Meadow (spring-physics grass) or Water (body-driven waves).
- Bots fill every arena. Works on phone (touch joystick + BOOST) and PC (mouse, Space/W to boost).

Multiplayer connects players directly (WebRTC via the free PeerJS service). Some strict networks may block peer-to-peer.
